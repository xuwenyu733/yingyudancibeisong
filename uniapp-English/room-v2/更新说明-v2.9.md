# 宠物小屋 v2.9 更新与使用说明

本次按确认的范围修改：积分兑换宠物、补充模型、修复购买和仓库流程、编辑个人主页和上传头像、升级徽章造型。

## 启动

先完整解压压缩包，再双击 `StartPreview.cmd`。需要 Python 3；页面会在浏览器打开。不要直接双击 index.html。也可运行 `python serve.py --port 8877`，避免和其他旧版预览占用同一端口。

主页面：`/`。四款模型及坐下/起立预览：`/examples/pets.html`。

## 新增功能

- 商店新增「宠物」分类：默认杏橘狐免费拥有；云朵兔 300 积分、薄荷猫 400 积分、可可熊 500 积分、星光企鹅 650 积分。
- 兑换成功自动换成对应的真实 3D 模型。已拥有的宠物可以免费切换；刷新后保留选择。
- 四款独立 GLB 文件位于 `assets/pets/`，带 idle、walk、sit、stand 动画；房间内兼容行走、坐下、起立、浇水和庆祝。
- 「屋内家具」列出房间中的家具，可直接收回仓库。仓库只显示当前收纳中的家具，摆回免费。
- 主页可编辑昵称，从设备相册/文件选择器上传 JPG、PNG、WebP 头像；自动居中裁剪成 192px 方形并压缩，也可恢复默认头像。
- 等级徽章分五档：1 级青铜圆牌、4 级银盾、8 级金星、12 级晶石、16 级王冠。主页显示进阶预览，勋章墙按类别显示对应图案。

## 修复内容

- 已拥有的家具即使余额低于售价，也能免费从仓库摆回；按钮不再错误显示积分不足。
- 购买/收纳/摆回保存失败时回滚场景、布局和账户；恢复原对象，避免重复注册和资源被提前销毁。
- 启动时先按库存剔除已收纳家具，再建立布局注册表，避免刷新后家具在房间和仓库同时出现。
- 所有座位均可收起；没有座位的房间仍可购买、摆放和保存。
- 台灯摆回时正确吸附到可用台面；请先收起台灯，再收起承载它的柜子或桌子。
- 固有家具默认位置被占用时尝试其他空位；空间不足会给出提示。
- 扩建后重新摆回装饰画会贴合当前后墙。
- 防止两个旧页面互相覆盖积分或购买记录，新增交易记录长度和安全整数检查。
- 修复默认头像空白、昵称被定时刷新覆盖、保存失败无反馈、主页就绪判断和日历星期错位。
- 存档导入导出兼容宠物产权和自定义头像；旧版账户自动补齐默认宠物，不清空原积分、家具与布局。

## 接入 API

新增 `api.purchasePet(sku, requestId)`、`api.selectPet(sku)`、`api.setProfileAvatar(dataUrlOrNull)`。

`api.getShop().pets` 返回 `{catalog, owned, active}`。头像由 `api.getProfile().profile.avatar` 返回。

宿主桥接支持同名命令；使用个人主页时同时引入 `shop.css` 与 `profile-upgrade.css`。默认角色会恢复已选宠物，自定义 `characterFactory` 仍保留宿主设置。

## 保存与验证

当前整合包沿用原版的浏览器本地存档与体验积分；正式应用由宿主对接真实学习记录/服务端账户。相册选择的是本机文件，整合包不会将头像上传到外部服务。浏览器原站点/端口不变时自动沿用旧存档；更换端口或浏览器时，可用宿主 API 导出/导入存档。
