# 改版说明 · v2.8（批次 1：补签 · 勋章详情 · 周报 · 主题 · 存档与工程）

> 本版为「纯前端体验批次」：只改前端与纯逻辑，不依赖宿主后端与美术资源。完整变更见 `CHANGELOG.md`。

## 一、新玩法/新界面

- **补签卡**：`makeUpCheckIn()` 花 100 积分补上「昨天」的签到缺口（不发经验/积分），每月限 3 次、次月重置；个人主页签到卡显示「补签昨天（100 积分，本月 n 次）」按钮，余额不足自动隐藏。幂等：扣积分失败自动挂账，重试按 `eventId` 补扣、绝不重复扣。
- **勋章详情与搜索**：勋章墙顶部搜索框按名称/描述过滤；点击任意勋章展开详情条（含解锁日期 `unlockedAt`），支持键盘 Enter/空格。
- **周报点阵**：主页新增「近 7 天签到 n/7」点阵，跨月自动衔接。
- **HUD 快捷签到**：房间就绪即显示，今天未签时可不开面板直接签到。
- **日间/夜间主题**：主页 header 🌙/☀️ 切换，配色走 `--room-*` CSS 变量，记忆到 localStorage；默认日间，夜间覆盖面板核心配色层。

## 二、数据与工程

- **存档导出/导入**：`api.exportArchive()` 得到完整存档 JSON；`api.importArchive(json)` 校验后写入本地（256KB 档案上限），**刷新页面重新挂载后生效**（不做热替换）。
- **迁移框架**：`migrations.mjs` 支持注册 `from→to` 迁移并按路径逐级升级，缺迁移/失败均有明确错误码。
- **存储配额提示**：`storage.mjs` 统计占用，超 80% 提示备份，满额提示导出。
- **音效模块**：`sfx.mjs` 8 组预设，无音频上下文环境静默；静音/音量/销毁齐全（当前未接入界面音效，供后续使用）。
- **i18n**：`i18n.mjs` 中/英双语键值（HUD/签到/补签/主题/确认），供后续换肤切换语言。
- **mock 服务端持久化**：`node server-proto/mock-server.mjs 8787 data.json` 可把账本与判重状态落盘，重启继承。
- **自动降画质**：连续 4 次帧率 <45fps 自动切低画质（像素比 1、关阴影），`metrics.autoDowngraded` 上报，纯渲染兜底不影响存档。

## 三、测试与发布

- 测试 198 → **214**：新增 `tests/batch1.test.mjs`（补签全路径、spend 幂等、勋章解锁时间、周报、存档回环、迁移、配额、音效、i18n、mock 持久化、幂等审计、400 步随机模糊、d.ts 同步、定时器清理审计）。
- 新增 `scripts/release.mjs`：`node scripts/release.mjs [major|minor|patch]` 一键升版 → 语法检查 → 全量测试 → 重建 `manifest.json` → 打 zip。

## 四、边界与诚实声明

- 浏览器内点击链路（补签、主题、快捷签到、勋章详情）由 Node 层与挂载契约覆盖；浏览器内逐项人工点击请在预览页完成（当前环境无视觉回读）。
- 导入存档需要刷新重挂载；补签扣积分失败会自动补扣。
- 主题切换只覆盖主页核心配色层；商店与房间其余样式保持原样。
- 自动降画质是渲染兜底，不影响数据。

# 改版说明 · v2.5（个人主页 · 等级 · 签到 · 勋章墙）

本版新增**个人主页**：可设置男女头像与昵称，查看等级/经验/学习时长/连续坚持天数/累计签到，每日签到给少量经验与积分（连续天数越多奖励越高），每个等级达成发放积分奖励，并附带一枚**勋章墙**（17 枚成就，含学习、签到、等级、购物、扩建）。

## 一、等级体系（profile.mjs）

- 等级 1–20 级，每级升级所需经验线性递增：1→2 需 100，2→3 需 160，3→4 需 220……（公式 `100 + 60×(当前级数−1)`）。
- 达到新等级发放积分奖励：升到 2 级 +50，3 级 +75，4 级 +100……（公式 `50 + 25×(新级数−1)`），奖励走 `economy.reward()` 幂等入账，不会重复发放。
- 经验来源：每日签到（少量）+ 学习奖励联动（房间 API 的 `creditLearning` 成功时按「每个新词约 20 分钟、每次复习约 10 分钟」顺带累计学习时长；时长本身是展示/勋章数据，不直接换经验）。
- `getProfile()` 返回等级名称（小小学员 → 荣誉导师）、当前等级进度（本段经验/本级所需）、满级标记。

## 二、签到（profile.mjs / room.js `api.checkIn()`）

- 每天一次（按设备本地日期），连续签到天数：昨天签过则 +1，断签归 1。
- 奖励随连续天数递增，每满 7 天额外加一次周期奖励：
  - 经验 = `5 + 2×(连续天数−1)`（第 1 天 5 → 第 30 天 63），每满 7 天再 +20；
  - 积分 = `3 + (连续天数−1)`（第 1 天 3 → 第 30 天 32），每满 7 天再 +10。
- 签到积分与升级奖励合并成一个幂等事件入账（`checkin:YYYY-MM-DD`）；若账本正忙/写失败，积分挂“待入账”，下次打开主页或签到自动补账，不会多发也不会丢。
- 同日重复签到返回 `ALREADY_CHECKED_IN`，不重复给奖励。

## 三、个人主页 UI（scene-profile.js）

- 右上角新增「Lv.n + 等级名」入口，进入右侧滑出面板：男孩/女孩头像切换（程序生成的狐狸头 SVG，区分刘海/蝴蝶结/腮红）、昵称编辑、等级进度条、学习时长、连续坚持、累计签到、今日签到按钮（含明日预告）、勋章墙三列网格（未解锁灰显）。
- 纯视图模块：只调 `api.getProfile()/checkIn()/setProfileGender()/setProfileName()`，不直接触碰存储，与商店面板同构，可单独嵌入宿主。

## 四、勋章墙（17 枚）

签到类：初次签到、连续 3/7/14/30 天、累计 7/30/100 次；学习类：累计 1/10/50 小时；等级类：达到 3/5/10 级；成长类：第一件家具、第一次扩建、集齐全部家具。达成即时解锁并持久化，解锁时发 `badge-unlocked` 事件。

## 五、框架链接与存储

- 新增 `economy.reward({eventId, points})`：与学习奖励并列的通用积分入账（独立幂等表，旧存档自动补 `claims.rewards:[]`，向后兼容）。
- 个人主页账本独立存档 `storageKey + '-profile-v1'`，与积分账本同款同步事务/白名单校验/写失败回滚；两账本都不写全局、不访问宿主 window（显式 localStorage 或注入适配器）。
- 桥接白名单新增 `getProfile/checkIn/setProfileGender/setProfileName/addStudyTime`，参数在桥接层校验后才到达房间 API（性别枚举、昵称 ≤40 字符、时长 0–86400 整数、无多余字段）。
- `room.d.ts` 同步 `ProfileState/ProfileBadge` 与五个新接口；`manifest.json` 重建为 79 文件。

## 六、验证

- Node 测试 **164 → 178 全通过**：新增 10 项个人主页账本（等级公式往返、签到奖励递增/周期峰值、连续/断签、当日幂等、待入账补偿、升级奖励并入待入账、勋章解锁与持久化、头像/昵称/时长校验、损坏存档拒绝写入、勋章目录稳定性）+ 3 项 economy.reward（幂等、独立于学习事件、跨重载、旧档无 rewards 兼容）+ 1 项桥接个人主页指令路由 + 畸形参数（性别/昵称/时长/多余字段）拦截。
- 浏览器真实挂载：v2.5.0 `ready`，HUD「Lv.1 小小学员」入口渲染，无报错，帧率 57–60fps。
- 未完成项沿用：真实儿童样本、原家具授权核验、uni-app 真机联调、服务端积分鉴权。

# 改版说明 · v2.4（2026-10-25）

本版新增**花盆浇水交互**：悬停盆栽出现提示，点击后无论狐狸坐在沙发还是软凳上都会自动起立、走过去弯腰浇水；同时把盆栽挪到角色可达的位置，并把“座位/浇水落点解析”统一成一个可测模块。

## 一、花盆浇水（room.js / decor.js / seats.mjs）

- 可浇水目标两个：房间自带的地面盆栽 `floor-pot`，以及商店购买后可摆放的四叶草盆栽 `shop-clover-planter`（买到后同样悬停/点击浇水）。
- 悬停盆栽时气泡提示「给花浇水」；浇水完成 6 秒内再悬停显示「刚刚浇过水」。**悬停只提示、点击才动作**，与沙发/软凳/台灯一致。
- **点击花盆后无论当前状态都会自动完成动作**：坐着 → 先起立 → 走过去；走向别的座位途中 → 取消换座改去浇水；正在走路 → 改道；正在浇水 → 忽略重复点击。
- 新状态 `watering`：角色面向盆栽弯腰两次（整体前倾 + 根节点起伏），盆栽上方同步落下淡蓝色小水珠（纯几何特效，不参与碰撞/交互），约 1.7 秒后回到站立；浇水期间按移动键立即取消并恢复行走。
- 事件：`water-start` / `water-done` / `water-blocked`（盆栽被家具围死时）；`getState()` 新增 `watering`（是否正在浇水）、`waterTarget`（目标盆栽 id）；版本升至 2.4.0，`room.d.ts` 同步。

## 二、盆栽位置修正（重要）

- 地面盆栽原在 `[2.55,0,-1.30]`，恰好落在沙发“碰撞盒半深+宠物半径”的膨胀区内——角色**永远走不到**，只是没被点过而已。v2.4 迁到前侧开阔处 `[1.85,0,1.60]`（默认布局下通过真实碰撞布局测试：盆栽自身与浇水落点都在所有膨胀盒之外、且从出生点可寻路到达）。
- 位置常量 `FLOOR_POT` 由 `decor.js` 导出，浇水落点定义在 `seats.mjs` 的 `WATER_TARGETS`（局部 approach/facing，随矩阵自动换算）。

## 三、可测性重构（seats.mjs）

- 把 `resolveSeatApproach` 的“候选落点 + 碰撞/边界校验 + 寻路验证”逻辑泛化为 `resolveApproach(root,id,fitted,opts)`；座位与浇水目标共用。新增 `fitWater` / `resolveWaterApproach`，商店盆栽被拖动/旋转后浇水落点依然正确。

## 四、验证

- Node 测试 **150 → 163 全通过**：新增 4 项浇水换算（目标配置完整性、盆栽落点换算、默认布局可达性回归、旋转商店盆栽）+ 5 项状态机转换（空闲点击后走+浇、坐姿点击先起立、移动键取消、浇水时点座位切换、浇水请求顶替排队换座）+ 1 项浇水手臂姿势契约 + 3 项商店摆放排序。
- 浏览器真实挂载：v2.4.0 `ready`、`watering/waterTarget` 字段就位、60fps、无报错；三角面 189,512、绘制调用 181（浇水水珠在浇水时才启用，不影响常驻开销）。
- 未完成项与 v2.2 相同：真实儿童小样本测试、原家具授权核验、uni-app 真机联调；另外“商店盆栽的实际购买与拖动浇水”只在 Node 侧验证了换算，页面上的完整链路请你实测。

## 五、本轮优化（同 v2.4 交付）

- **浇水手臂姿势**：浇水时狐狸双肩前伸、肘微屈、头颈微低、尾巴微翘——像真的端着一把水壶；`pose.setWatering(weight)` 只叠加在既有姿态之上，0 时与原本完全一致，坐/立关键帧契约与 GLB 动画不受影响。
- **商店摆放靠墙优先**：新增 `placement.mjs`，购买家具的候选落点按“靠近墙壁优先”排序再逐个尝试（候选集合与可放置判定不变），新家具不再抢着挡在过道/画面中央。
- **键盘可访问**：悬停某物体时按 **Enter** 等同点击（可隔空坐下/开灯/浇水）；浇水时按 **Space** 也能取消（原来只有移动键能打断）。
- **浇水反馈增强**：水珠由 8 粒增至 10 粒，盆栽口沿在浇水时出现一圈“湿润泥土”深色盘（呼吸式微缩放），浇水结束随特效一起消失；全部特效隐藏时零渲染开销。

# 改版说明 · v2.1（2026-10-25）

本版在 v2 基础上做了三件事：**面向 6–14 岁儿童的原创角色造型修整**、**更真实的行走/坐下/起立动画**、**面向宿主集成的轻量增强**。未引入任何第三方模型、贴图或现成 IP 素材，角色仍为程序几何原创。

## 一、儿童偏好调研结论（本轮新增）

依据公开研究报告整理出的通用设计原则（非复制任何角色 IP）：

- 台湾文策院《臺灣圖像角色消費與市場研究報告》(2025)：4–14 岁儿童普遍偏好**圆润线条、动物类、高辨识度、五官与情绪清晰**的角色；小学生偏好大眼睛、线条清晰、轮廓明确；初中生偏好细节与设定更丰富的角色。
- 日本 CHARACTER DATABANK《CharaBiz DATA 2025》《子ども調査 2025》：3–12 岁最受欢迎角色（哆啦A梦、宝可梦、小小兵等）共性为柔和圆型轮廓、拟人化、高辨识造型、清晰表情。
- 幼态图式（Kindchenschema / 婴儿图式）研究：大头、大眼、圆颊、小鼻、短肢体是跨文化通用的可爱感知要素。

应用方式：只采用上述**通用原则**调整原创狐狸的比例与配色，不参考任何具体 IP 的形象。

## 二、角色造型修整（characters/original-fox.js）

| 项目 | v2 | v2.1（kid 预设） |
| --- | --- | --- |
| 头身比例 | 常规 | 头部放大 ~9%，更圆润 |
| 眼睛 | 普通 | 增大 ~30%，新增深色瞳孔 + 更大高光 |

## 三、动画真实感提升（runtime 与 GLB 同步生效）

### 行走
- **竖直起伏**：脚步交换时重心最低、迈步中段最高（每步幅两次起伏），烘焙进模型根节点（GLB `OriginalFox.position`）；其他引擎导入即可见。
- **骨盆重心侧移**：迈步时沿左右小幅横移（不用 z 轴旋转，保证脚掌始终保持水平）。
- **支撑弯膝**：双脚交换时两膝轻微弯曲卸力，迈步中段支撑腿伸直。
- **躯干前倾 + 头颈微动 + 摆臂随速度缩放**：快走大步、慢走小步，接近真实步态 `speedBias`。

### 坐下（sit 1.45s）
阶段细化为 7 段：前倾准备 → **沉髋蓄力**（新增）→ 屈髋屈膝 → **抱膝收敛**（新增）→ 落臀缓冲 → **落座回稳**（新增，坐垫轻微回弹不压穿）→ 坐稳。手部在屈髋落座阶段前伸扶垫，落座后收回。

### 起立（stand 1.2s）
阶段细化为 5 段：起立前倾 → **撑膝发力**（新增，双手撑膝蹬腿）→ 蹬腿伸髋 → **起身回正**（新增）→ 挺身站稳。

原 v2 的锚点帧（时间/数值/标签：前倾准备 .27s、屈髋屈膝 .73s、落臀缓冲 1.12s、坐稳 1.45s；起立前倾 .32s、蹬腿伸髋 .83s、挺身站稳 1.2s）保持不变，**动画时长的对外契约没有改变**，已有宿主状态机无需改动。
