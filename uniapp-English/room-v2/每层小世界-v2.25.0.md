**每层都是一个可以保存的小世界 · v2.25.0**

在「城堡 / 楼层」中，每层都有自己的家具摆放、房型布局、配色、墙画、家具手绘和照片。修改会自动保存，切去其他层再回来或刷新后，继续读取这一层的布置。

在当前楼层的「这一层的小世界」中：

1. 给喜欢的布置填写名字，点击「保存此层」创建命名存档点；每层最多保留 5 个。
2. 点击某个存档点的「读取」，核对楼层和名字后确认；只恢复这一层。
3. 「导出这一层」下载独立 JSON 文件；「导入这一层的存档文件」可从文件读取对应楼层的方案。
4. 不需要的存档点可以删除。删除存档点不会删除当前正在使用的装修。

共享积分、已购收藏、宠物、个人资料和学习进度继续共享，不随单层装修回档。读取旧布置时，后来买的家具仍在收藏中，未摆放的家具回到本层仓库；已经解锁的房型也保留。文件所属楼层不一致时会拒绝导入，防止误覆盖其他层。

装修模式或存在尚未保存的手绘草稿时，先完成或放弃草稿，再保存、读取或切楼层。完整庄园的导出、备份和账号迁移仍可使用，并且会包含每层命名存档点。

MySQL 版新增数据库版本 1.1.0，对应 `room_world_saves` 表，每个账号的每层分别保存当前装修和命名存档点，与完整存档一起提交。数据库目录可按账号和楼层查看。新安装使用初始化脚本；旧数据库升级使用 `升级楼层存档数据库.cmd`，会先备份再升级。
