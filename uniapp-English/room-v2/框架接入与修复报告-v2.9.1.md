| 问题 | 修复结果 |

| Vite 构建只产出 JS，家具 GLB 没有进入产物 | 默认资源改为三个可静态分析的 URL，构建实际产出哈希模型文件 |
| 相对 assetsBaseUrl 在框架子目录里失效 | 按 canvas 所属文档的 baseURI 解析，同时支持按家具覆盖 assetUrls |
| 只有场景挂载函数，框架容易漏卸载商店、主页和样式 | 新增 mountPetHouse，统一管理场景、面板、样式、桥接和取消信号 |
| 已卸载的 API 仍能改昵称、头像、学习时长或结算奖励 | 统一生命周期守卫；加载、释放和要求重新挂载时拒绝写入 |
| 导入存档后旧内存仍可能继续运行 | 导入成功进入 reload-required；重新挂载后读取新存档；WebGL 恢复事件也不能解除冻结 |
| 低帧率降级向冻结对象赋值，导致场景报错 | 为实例维护可变画质状态，真正切换到低画质并补回归 |
| parent 模块挂载 iframe 内 canvas 时可能使用外层存储 | 默认适配器来自 canvas 的所属窗口；访问失败明确反馈，不借用其他账户存储 |
| 首次空存档多实例覆盖、宿主存储回调重入覆盖 | 比较空键版本并增加共享适配器/键的写入锁 |
| 旧实例在查冲突前给待结算奖励入账 | 先检查当前档，再结算；重复/乱序签到与解锁事件的保存顺序也已修复 |
| 导入只校验外壳，坏存档或第二键写失败导致部分覆盖 | 严格校验两本账、写前备份、失败回滚；无法完整回滚时明确返回 recoveryRequired |
| 桥接读取原型链/访问器、重复请求参数顺序误判 | 只接收自有普通 JSON 数据、只调用 API 自有方法，规范化参数用于幂等 |
| 桥接存档字符串上限小于可导出数据 | 与完整存档统一为 1.5MB UTF-8 上限 |
| 按钮嵌进宿主 form 会提交表单 | 所有交互按钮明确 type=button |
| 商店卸载把借来的装修按钮一并删掉 | 释放时还原按钮，重复挂载仍可装修 |
| 多房间 Escape、定时器、头像读取与异步请求互相干扰 | 按实例及焦点处理，卸载后终止回调、临时 URL 和计时器，阻止重复请求 |
| 桌面窄容器仍套用宽屏样式；canvas 样式影响宿主 | 使用容器查询并限定样式范围，实际验证 280px 与 320px 容器 |
| 运行中场景报错只留下冻结画面 | 完整入口显示错误并回调 onError，释放面板，避免重复报错 |
| 旧版预览服务未退出，启动新版后可能仍看到旧页面 | Windows 预览服务独占监听端口，被占用时选择下一端口。依据 [Microsoft 的端口选项说明](https://learn.microsoft.com/en-us/windows/win32/winsock/using-so-reuseaddr-and-so-exclusiveaddruse) |
| 发布包可能带入测试 node_modules 与缓存 | 只按 manifest 清单打包，排除依赖、生成的框架产物及缓存 |

## 推荐接入

不要把 index.html 或 bootstrap.js 复制进框架组件。保留整个目录结构，使用完整入口或现成组件。

```js
import {mountPetHouse} from './pet-house/pet-house.js';
const room = mountPetHouse({
  container: document.querySelector('#pet-room'),
  storageKey: `pet-house:${userId}`,
  timeZone: 'Asia/Shanghai',
  onError: error => console.error(error),
});
const api = await room.ready;
// 路由/组件卸载时：room.dispose();
```

- React 使用 `frameworks/ReactPetRoom.jsx`；Vue 使用 `frameworks/VuePetRoom.vue`。
- uni-app H5 包装位于 `frameworks/UniPetRoom.vue`，不要在原生小程序画布上直接执行 DOM 挂载代码。
- 自动加载样式；若由宿主统一管理 CSS，可传 `styles:false` 并导入 `styles.css`。
- 每个登录账户使用独立、稳定的 storageKey。切换用户时让组件重新挂载。
- storageAdapter 必须同步提供 getItem/setItem；可回滚导入新账户键还需 removeItem。异步宿主存储应由宿主先读取到缓存并提供同步适配层。
- importArchive 成功返回 relaunchRequired 后，React 更新组件 key、Vue 调用组件 ref 的 remount，或手动 dispose 后重新 mountPetHouse。
- 代码导入可以在 SSR 环境执行；创建小屋必须放在客户端挂载生命周期中。[React StrictMode](https://react.dev/reference/react/StrictMode)、[Vue 生命周期说明](https://vuejs.org/guide/reusability/composables)。
- 正式账户权限、积分发放与跨设备一致性仍属于宿主后端。同步浏览器存储的回滚不能代替数据库跨进程事务。
