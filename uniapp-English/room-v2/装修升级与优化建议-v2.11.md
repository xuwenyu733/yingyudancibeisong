# 宠物小屋 v2.11.0：装修升级与优化建议

基于提供的 `original-pet-room-v2.10.0.zip` 修改，日期：2026-10-27。

## 本次已完成

1. **装修面板可折叠**：点击「收起设置」。家具名称、旋转、收回仓库、取消和完成保存始终保留；折叠状态在本次页面内再次进入装修时沿用。
2. **底部独立一横排家具栏**：展示所有已拥有家具，标注「房间中」或「仓库」。面板折叠后家具栏仍可使用。
3. **点击选用**：点击房间中的家具卡片即可选中；点击仓库卡片会自动寻找可用位置摆放，并选中新家具。
4. **拖拽摆放**：鼠标拖动卡片到房间里，松手指定落点。手机先向上拖出家具栏再摆放，左右滑动用于浏览。房间内已有家具也可从卡片拖动调整位置。
5. **横向切换**：左右按钮、触摸横滑、触控板横滑、鼠标滚轮均可浏览超出当前宽度的家具；到达边缘时按钮会禁用。
6. **摆放保护**：碰撞、越界或挡住伙伴时拒绝落点。仓库家具保留在仓库；已有家具恢复原位置。拖到房间以外、按 Esc 或窗口失去焦点会取消拖动。
7. **房间取景优化**：装修期间为底部家具栏预留空间，完整展示房间；商店和个人主页入口在退出装修后恢复。
8. **操作反馈与无障碍**：当前选中卡片高亮；交易中阻止重复操作；支持 R 旋转、Esc 取消当前拖动或装修，支持键盘 Tab / Enter 操作按钮。成功提示自动收起，避免长期遮挡房间。
9. **等待恢复**：进入装修的等待增加 8 秒超时，避免伙伴动画未完成时装修按钮一直不可用。
10. **存档修复**：修复「调整家具 → 收回/取出其他家具 → 取消装修 → 刷新」可能重新出现未保存位置的问题。取消时同步恢复后的布局；写入失败则保留会话，允许重试。

**保存规则**：位置调整通过「完成保存」确认，「取消」恢复本轮位置调整；收回和取出家具即时保存。这沿用项目原有的仓库事务规则，界面已添加说明。

## 后续最值得优化的地方

| 优先级 | 优化项 | 当前表现与建议 |
| --- | --- | --- |
| 高 | 真实家具落点预览 | 仓库拖入时显示名称提示，松手后才完成碰撞与通路检查。建议先创建半透明模型，随指针移动，用颜色标出有效落点；点击与拖动继续共用同一事务校验。 |
| 高 | 撤销 / 重做 | 目前支持单次拖动失败回退和整轮取消。建议记录移动、旋转的操作历史，并明确收纳事务能否撤销，避免库存与布局不同步。 |
| 中 | 家具模型缩略图、分类与筛选 | 目前以 emoji 识别家具，桌子/柜子等类型图标相近。建议复用商店插画或离线模型缩略图，增加「全部 / 房间中 / 仓库」与家具类别筛选。 |
| 中 | 键盘精细移动与对齐 | 目前精确位置主要靠拖动和 0.1 米吸附。建议增加方向微调、细步长切换、靠墙和家具边缘对齐；快捷键仅在装修区域获得焦点时生效。 |
| 中 | 家具较多时的拾取性能 | `decoration.js` 的拾取会在 pointermove 中更新模型矩阵并射线检测。建议先用性能数据确认瓶颈，再合并到每帧一次，缓存可编辑对象列表。 |
| 低 | 布局方案与重置预览 | 目前使用当前布局保存/取消，已有导入导出 API。建议增加多套方案、重置前预览和明确的确认入口，方便尝试不同风格。 |

这些建议尚未实现，避免把未完成内容当成新版功能。

## 预览与运行

- 解压新版完整压缩包，双击 `StartPreview.cmd`（需要 Python 3），按终端地址进入。
- 已安装 Node.js 时也可在项目目录运行 `node serve-demo.mjs 8991`，打开 `http://127.0.0.1:8991/`。
- 从「装修」进入，点击「收起设置」，底部家具栏可独立使用。
- 桌面截图：`previews/装修家具栏-桌面-v2.11.png`；手机截图：`previews/装修家具栏-手机-v2.11.png`。

`view.js`、`room.css` / 自动合并的 `styles.css`、`decoration.js`、`room.js`、`layout-manager.js`；版本元数据与变更记录已更新至 2.11.0。新增两组测试，并补充原有库存事务回归测试。
