宠物小屋 · v2.21.0
==================
源码与本地演示完整包。新增互动与宠物四边安全距离修复均已包含；旧版说明保留供回溯。

【怎么用】
1. 将 ZIP 完整解压到一个新文件夹，不要直接在压缩软件里启动。
2. 双击 StartEstatePreview.cmd，需要安装 Python 3.8+，无须另装 Python 包。
3. 浏览器会打开城堡楼层演示，默认 http://127.0.0.1:8870/?preview=estate 。
   端口被占用时自动尝试后续端口，请使用启动窗口实际打印的地址。
4. 关掉启动窗口即停止服务。开发回归可执行 npm test，需要 Node 20+。

【本版重点】
家具自由手绘与橡皮/撤销/重做、礼物真实家具及收纳、成长任务与三阶段程序造型、19 种成就纹样、
可跳过搬家过场、双指旋转缩放、实操首次向导、本地中文昵称语音选项，以及宠物墙边/四角安全距离。
保留城堡仅叠层、全房间共享积分、物品/勋章/成就获得时间、一键全收纳和全局静音/音量。
已删除寄小屋明信片功能。

【数据与说明】
数据保存在当前浏览器当前地址的本机存储中。不同端口或浏览器的存档彼此独立。
演示进度不随源码 ZIP 分发；当前运行中的测试存档保持不变。
完整更新、功能入口、验证范围和未完成内容见《互动补全与墙边修复-v2.21.0.md》。
另一边新版本的目录尚未提供，本包尚未完成跨项目迁移或云端接入。
