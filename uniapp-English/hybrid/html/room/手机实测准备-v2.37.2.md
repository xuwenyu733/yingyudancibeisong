日期：2026-11-10。测试准备工具位于电脑工作区 `work/`，用户入口位于桌面“仓鼠屋手机实测准备”。测试工具不进入产品部署包。

## 本次发现并修复的兼容问题

通过真实局域网 HTTP 地址打开房间时，`crypto.randomUUID` 不可用，入屋报错 `win.crypto.randomUUID is not a function`。相同调用还出现在聊天、生活请求、试摆兑换和原生照片临时编号中。

新增 `request-id.mjs`：优先使用原生 `randomUUID`；不提供该方法时，用 `crypto.getRandomValues` 生成符合 UUID v4 格式的编号。不使用弱随机编号；如果连安全随机数也不支持，明确报错。请求重试仍保留原编号，不改变已有去重规则。

同时补全发布清单中漏列的根目录运行模块，包括受保护入口、在线记录、生活和屏幕适配模块，避免只按清单交付时缺少依赖。App 内嵌仓鼠屋同步同一修复。

## 准备内容

- 局域网扫码测试页，使用专用 8773 端口；电脑入口与安卓 USB 入口同时可用。
- 两个专用测试账号，各自保存；A 初始一层、10,000 测试积分；B 初始两层、9,400 测试积分。重启保留测试进度，不覆盖孩子原存档。
- 18 项检查表：屏幕/全屏/缩放/滚动、后台与断网、宠物与装修、组合与积分、两层与备份、好友参观、装修码和生活场景。
- 手机上填写并保存结果到电脑，或下载文字记录；错误诊断只记录必要信息，不录屏、不录音。
- 一键启动、停止、刷新二维码、安卓 USB 端口转发，以及仅在需要时使用的专用防火墙规则工具。
- 手机测试代理拒绝数据库管理路径、未配对入口与非测试账号会话；后端使用既有普通应用数据库凭据，凭据不进入桌面测试包。

测试助手使用独立的本机服务，不修改学习页或管理后台。数据库无结构变更，仍为 1.6.2；后端产品版本仍为 1.6.3。

## 验证与边界

- 前端完整回归：893 项通过，0 失败、0 跳过；新增原生及 HTTP 回退、UUID 格式和随机源失败检查。

- 严格公共接口类型检查通过。
- 本机已验证启动、停止、重新启动和保留测试账号；尚无连接的安卓设备，USB 转发和真实手机触摸/全屏需实际连接后确认。

全屏及方向锁定还受浏览器支持、用户操作和当前全屏状态等条件影响；USB 本机入口用于对比，不代表能让浏览器不支持的接口变为可用。方向锁定一般要求移动设备和全屏状态，参见 [ScreenOrientation.lock 文档](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)。USB 端口转发可不依赖局域网配置，参见 [Chrome 官方本地服务器调试说明](https://developer.chrome.com/docs/devtools/remote-debugging/local-server)。

局域网 HTTP 测试不是公网正式部署验收。真机机型、系统、浏览器版本、录像和实际问题以用户后续记录为准。
