# 仓鼠屋两轮自检与修复 · v2.37.1

日期：2026-11-10。范围为仓鼠屋源码及 App 内嵌的仓鼠屋副本。本次没有修改学习页、管理后台、数据库结构或孩子的真实存档。

## 第一轮：装修事务、积分与存档

发现并复现：收藏组合还在预览时，点击“固定位置”能够修改家具定义；撤销操作也可能把未确认的预览放入重做历史。部分触摸入口会先取消预览再继续拖动，与“确认后才保存”的提示不一致。

修复：

- 组合预览期间禁止固定、撤销/重做、拖动、双指变换、收纳/取出、精确移动、配色及整体整理。按钮呈现不可用状态，键盘、事件处理和公开 API 也有同样保护。
- 确认组合后才产生一条可撤销记录；取消返回预览前的完整布局。离开装修仍要求先确认或取消。
- 销毁装修实例时先撤销预览，再关闭编辑事务，避免清理顺序把未保存的位置带回来。
- 点击重叠家具后，候选框显示实际选中的物件，而不是总显示最前面一件。
- 保护只作用于装修和家具交易，不拦截学习积分入账或补签。

验证：修改前真实浏览器用例在“未确认预览不能固定家具”断言失败；修复后通过。独立 MySQL 账号验证了固定、撤销、双指、API、仓库入口均受保护，取消恢复、确认后的撤销、刷新保持布局以及积分/宠物不变。另有仓库内浏览器回归测试覆盖相同行为。

## 第二轮：宠物预览性能、兼容与资源释放

发现并复现：301 CSS 像素宽、设备像素比例 1.5 时，画布尺寸比较的舍入方式与 Three.js 不一致，每帧都会重新调整画布。原预览滚出屏幕后也会继续绘制，且没有图形上下文丢失后的状态提示与恢复控制。

修复：

- 按实际 CSS 尺寸和像素比例缓存尺寸，只在尺寸变化时调整画布，保持相机比例一致。
- 预览绘制限制在最多每秒 30 帧；滚出可视区域、隐藏、切到后台时停止绘制，返回后恢复。
- 图形上下文丢失时停止绘制、暂时禁用动作按钮并提示恢复；恢复后重建画布尺寸并继续显示。
- 没有 ResizeObserver / IntersectionObserver 的旧 WebView 也能打开、调整窗口和关闭预览。
- 关闭时停止动画并释放指针捕获及宠物资源；销毁组件时再移除观察器和图形资源。额外手指不会接管正在进行的旋转。

验证：修改前真实 WebGL 回归检测到连续 5 帧又调整了 5 次画布；修改后尺寸稳定时不再调整。测试使用 WEBGL_lose_context 模拟真实图形上下文丢失/恢复，并验证离屏暂停、返回恢复、隐藏、重新打开、销毁以及无观察器兼容分支。
