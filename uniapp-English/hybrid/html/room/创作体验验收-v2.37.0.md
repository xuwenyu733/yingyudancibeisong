# 仓鼠屋创作体验 v2.37.0

改动范围：仓鼠屋源码、仓鼠屋后端数据投影，以及 App 内嵌的仓鼠屋副本。学习页、背单词流程和管理后台代码不属于这次改动。

## 操作入口

| 功能 | 入口 | 当前行为 |
| --- | --- | --- |
| 存档比对恢复 | 更多 → 存档备份 → 预览并恢复一层装修 | 对比本机与数据库副本，显示楼层保存时间、家具位置示意图和增减/移动件数。先确认再恢复；恢复前保留当前副本。 |
| 视野恢复 | 画面左上方「看全屋」「找宠物」 | 只修改相机视野，不改变房屋尺寸、家具比例或存档。 |
| 固定家具 | 装修 → 点选家具 → 固定位置 | 阻止拖动、旋转、收回及跨楼层移动；解除后才能操作。固定状态随装修保存，也支持撤销、取消。 |
| 选择被遮挡的家具 | 装修时点击重叠家具 | 出现候选选择框，也可在「组合与精确摆放」中按名字选择。 |
| 简易装修 | 装修面板 | 日常保留选取、移动、旋转、固定、收回、撤销、保存；碰撞盒参数仅显式 debug 模式显示。 |
| 多件同款家具 | 商店 → 已拥有的家具 → 再兑换一件 | 每件按标价扣积分、独立保存，最多同款20件；地砖仍是一套收藏重复免费铺设。商店显示拥有件数、本层摆放件数、可取用件数。 |
| 收藏局部组合 | 装修 → 组合与精确摆放勾选 → 我的家具组合 | 每个组合最多24件，最多12个收藏，两层共享。使用前将所需家具取到当前楼层，点击组合预览，再确认或取消。保留相对位置，摆好后可整体平移、旋转；碰撞或挡路会回退。 |
| 宠物3D预览 | 更多 → 我的宠物 → 更换宠物 → 选择品种 | 左右拖动或按钮旋转，可看走路、坐下、打招呼。预览免费，确认更换才扣分；世界中仍只有一只自己的宠物。 |
| 物种小动作 | 宠物安静站立时 | 兔子动耳、猫伸展、熊歪头抬爪、企鹅摆鳍；坐下、走路、浇水等状态会抑制闲置动作。 |

## 存档与数据库

- 初始家具和原有第一件家具继续使用旧编号；额外家具使用稳定的 `--copy-2` 至 `--copy-20` 编号。并发保存继续使用现有版本检查及原子事务。
- 同一件兑换家具移到另一层时，原层同时收纳；固定的家具禁止跨层移动。旧存档已有的多层显示不会在加载时被静默删掉。
- 恢复一层时保留当前积分、产权、宠物和共享组合。正在其他楼层使用的家具留在原层，不能通过旧备份生成免费副本。
- 冲突原始备份保留在该浏览器本机；这不是跨设备的云端历史备份。恢复面板仍可下载原始文件。空间不足时停止恢复，不覆盖旧记录。
- 无需新增表或删除数据，数据库结构版本仍为 **1.6.2**。后端程序版本为 **1.6.3**。
- `sys_save_slots.archive` 保存完整权威记录；`room_furniture.furniture_id` 区分每件家具，`item_sku` 仍对应商品种类。`inv_ownership` 是种类索引，不能用它的行数当家具件数。
- 在数据库客户端运行 `../backend/queries/家具件数与组合.sql`，依次查看「每件家具及位置」「同款拥有件数」「共享组合」。三个查询只读，普通应用数据库账号即可运行。

## 有设备或孩子参与后补充的观察

每项先让孩子自己操作，不提前指按钮，记录是否完成、误触位置以及是否需要帮助。不收集姓名、聊天内容等无关信息。

1. 在手机竖屏、横屏和平板上双指放大，再找到「看全屋」；观察房屋比例和按钮是否正常。
2. 找到宠物，进入更换预览，转动看看，取消退出；确认没有扣积分和多出宠物。
3. 选中一件家具，固定，再尝试移动，找到解除固定；检查提示是否容易理解。
4. 多选两件家具收藏组合，取消一次预览，再确认一次；观察是否理解预览与保存的区别。
5. 兑换第二件同款家具，去另一层取出，再回原层；观察是否理解“同一件移动”和“兑换新的一件”。
6. 在独立测试账号比较两份备份，选择一层恢复；观察能否辨认保存时间、楼层和家具位置。

目前没有连接的真实移动设备，也没有儿童试用观察记录。硬件手势流畅度、机型兼容性和孩子是否能独立完成上述操作，仍需实际观察。
