# 宠物小屋 v2.22.0

## 操作入口

- **装修**：调整家具、墙色；在设置区展开“帮这一层整理一下”，可“一键全收进仓库”或“恢复默认布局”。这两项已经从楼层管理移到装修中。
- **城堡 / 楼层**：新增或切换楼层，新增上限为4层。每层的布局、墙色、涂鸦分别保存；积分与收藏共用。楼层名字可留空，自动命名。新增楼层不扣分，原来的房间面积扩建仍按商城标价扣分。
- **动物拖动**：按住小狐狸或来访云朵兔，拖向地面位置；它们沿可走路径跟随，遵守房间边界与家具碰撞。小幅点击仍是抚摸，手指滑过8像素后才算拖动。触屏第二根手指不会抢走正在进行的拖动。
- **双宠与球**：点击云朵兔可一起玩；点击球，主宠走近后抬脚踢球，小兔会追球并踢回。球有滚动、反弹、摩擦与碰撞。
- **学习书架**：后墙有实体书架。原有宿主 `creditLearning({eventId,learned,reviewed})` 成功记入一次新学习后，会出现新书动画。同一事件不重复长书；最多显示最近32本，总记录仍保留。
- **涂鸦墙**：用手指或鼠标画画，保存后挂到后墙；每层独立保存，完整备份会包含画作。尚未保存的画作会阻止切换楼层，先保存或放弃草稿即可。
- **伙伴手册 → 家长设置**：可切换幼儿园/小学显示密度，以及中文、英语、日语的昵称语音和声线。

## 装修故障修复

原来的微风动画直接改变家具根节点的Z轴旋转，违反布局校验“只允许绕Y轴旋转”的规则，导致装修快照和编辑会话失败。现在动画只改变内部视觉节点，不会修改已保存的家具变换。进入装修时也会恢复实时画面。

整理操作先保存当前编辑，再执行收纳或归位，随后开启新编辑会话。若保存失败则不执行整理；交易失败会显示原因。积分和家具所有权保留。

## 按本轮反馈移除

相册、拍照、照片下载、分享明信片、实时天气与整个学习游乐场（题目、节拍、拖拽关卡、错题练习、录音）均不再提供入口或运行管线。原有外部学习积分与成长记录继续使用。旧试用存档中的相关字段仅用于兼容读取，不会激活这些功能。

## 存档与设备说明

默认页面启用楼层模式，自动承接原单房间存档。新建最多4层；若导入旧版已有5/6层的存档，会完整保留，禁止再新增。

语音使用设备已安装的本地TTS，调整语速与音高表现童趣声线；不含预录童声。设备没有对应语音时显示提示。仅切换语言不会下载或上传音频。

解压后运行 `StartPreview.cmd` 或 `node serve-demo.mjs 8899`，通过本地HTTP地址打开。不要直接双击 `index.html`，浏览器通常限制本地文件模块。

## 验证

运行 `node --test tests/*.test.mjs`。本轮新增覆盖装修根节点稳定性、4层共享积分、分层画作存档、宠物拖动与多指归属、球碰撞和新书动画，以及装修整理的保存/失败/并发行为。实际页面已检查装修入口与移除后的入口布局；具体测试计数见交付验证记录。
