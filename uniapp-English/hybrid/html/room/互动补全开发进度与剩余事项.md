# 互动补全：当前开发进度

日期：2026-10-29。本文所列后续改动已纳入 v2.21.0 发布范围，当前说明见《互动补全与墙边修复-v2.21.0.md》。开发源码仍在历史命名目录 `work/original-pet-room-v2.17.0` 内；先前 v2.20.0 ZIP 保留且不包含这些后续改动。

## 已接进当前模板

| 清单 | 当前行为 |
| --- | --- |
| 自由手绘 | 画笔、颜色、粗细、透明橡皮、撤销、重做、可撤销清空与保存；每件家具独立画稿。保存失败保留草稿；未保存时不能换家具或楼层，关闭手册仍保留。完整存档与楼层隔离均包含手绘。 |
| 宠物反馈与睡眠 | 五宠支持欢呼、鼓掌、蹭蹭，夜间蜷睡、闭眼与呼吸；轻柔合成呼噜声遵守全局静音和音量。动作结束或中断会恢复姿态。 |
| 昵称语音 | 家长设置的“语音喊昵称”默认关闭；仅选择设备本地中文语音，需真实点击解锁，支持试听、去重、静音和取消。无本地中文语音时明确提示，保留昵称气泡。 |
| 搬家过场 | 换楼层时保留旧画面并显示搬运遮罩；新房加入有限时长的镜头移动、墙体视觉扩缩、纸箱搬入与收起。支持跳过与减少动态效果，不修改存档中的碰撞根坐标；卸载时清理遮罩。 |
| 三阶段成长 | 幼年、少年、成年分别应用形体比例和独立几何服饰附件；少年需 7 个活跃日期，成年需 30 个活跃日期及累计学习 2 小时。手册显示下一阶段任务。 |
| 成就家具皮肤 | 全部 19 枚成就各有独立程序纹样和配色；获得成就后可自动关联家具，手册可选择已解锁纹样。未获得的纹样不能应用；手绘与纹样分层保留。 |
| 礼物家具 | 每份奖励对应独立免费 SKU，四类真实礼物模型可摆放、旋转、缩放、换色、贴纸、手绘及收纳。各层共享产权，摆放与仓库状态独立，不扣积分。 |
| 礼物到期 | 保留收藏、获得时间与记忆；禁止重新取出已到期礼物。到期自动收纳若遇到装修或写盘失败，会保留可见模型与碰撞，待可保存时重试，避免隐形障碍。 |
| 寻宝动作 | 有可达路径且宠物就绪时，使用现有导航出发，嘴部挂上临时道具，再返回放下。障碍拒绝与主动中断会清理道具，不强行穿墙。 |
| 首次实操引导 | 小宠物跟随当前目标移动，用实际“进入装修→拖动落地→成功旋转→保存”事件推进；支持跳过与重播，不能点下一步假装完成。 |
| 双指手势 | 普通家具双指连续旋转与等比缩放；固定设计尺寸的 0.5～2 倍限幅，反复捏合不会无限放大或缩没。结束一次提交，碰撞失败/取消/第三指/退出回滚。墙挂件双指调整大小，换墙沿用原按钮。 |
| 宠物墙边安全距离 | 四边统一按宠物身体半径加可见空隙收紧行走范围，包含开放的前沿与四角。键盘、点击寻路、自动巡游与座位接近使用同一边界；边沿点击不会让坐着的宠物起身或排队。贴边座位或屋内通路不足会提示调整家具，不能借坐下跳过边界。旧布局保留，已经恢复通路的座位不能再次被堵死；缩房会先寻找屋内安全落点，失败时回滚位置与布局。 |

先前的城堡仅叠层、共享积分、获得时间、全收纳、静音和明信片删除继续保留。

## 当前验证

- 全量 Node 回归：575 项，569 通过、0 失败、6 项可选 Playwright 浏览器测试跳过。声明严格检查与改动模块语法检查通过。
- 新回归覆盖：手绘笔画/橡皮/撤销/存档；五宠三阶段和睡姿恢复；寻宝合法路径与资源释放；19 种纹样；本地语音门槛；双指限幅/回滚；实操教程事件；礼物真实摆放、旋转、收纳、刷新与失败回滚；到期与装修/写盘失败交叉情况；切房途中卸载与未存画稿保护。
- 内置浏览器实测：自由画纸绘制、撤销/重做、保存后刷新仍贴在沙发；礼物摆放、旋转、爱心贴纸、成就纹样与刷新保留；共享积分不变；未存画稿阻止换楼层，主动放弃后可切层；搬家提示出现；成长任务展示；本地昵称语音试听接口接受播放请求；礼物缩略图加载正常。检查时控制台无 warn/error。
- 墙边专项：三种房型的八方向长时间移动、四边/四角路径、坐姿边沿点击、贴边座位拒绝，以及旧座位通路迁移和保存失败回滚。内置浏览器切到二楼空房后，各持续按方向键 7 秒，分别停在四个安全内角（x = ±3.74，z = ±3.44；实体房间半宽 4.4、半深 4.1），布局始终有效；点击最前方外沿仍保持屋内位置，控制台无 warn/error。
- 没有把程序化用例当成真实手机或长时间自然运行验收，也没有人工确认扬声器听感。

## 仍未完成或需要外部条件

1. **制作级美术与音频**：目前是程序化形体、几何服饰、骨骼姿态、纹样和合成音效。尚无三套独立雕刻的成长资产、录制动作、专业录音呼噜，以及逐成就手绘材质包。
2. **任意 3D 表面作画**：当前手绘在独立画纸上创作，按原比例贴在家具顶面；尚无直接在模型任意曲面涂抹、UV 展开编辑或多面画稿。
3. **整栋城堡与长剧情搬家**：目前为逐层房间和有限过场；尚无整栋城堡同屏、楼梯穿行、连续建筑编辑或长篇剧情分镜。
4. **真机与长期验收**：真实 iOS/Android 双指手感、多浏览器 GPU、持续运行、自然七天到期和人工音效试听仍需验收。六项历史可选 Playwright 用例未执行。
5. **旧时间记录**：不存在的原始获得时间无法补造，继续明确标注未记录。
6. **云端服务**：尚未接入线上账号、跨设备云同步、服务端签到时钟及积分校验；仍使用本地存储。没有用占位入口表示云服务已完成。
7. **另一边新版本迁移**：目标目录尚未提供，当前只完成本地模板与接口，未迁移或跨项目联调。
8. **大量绘画存储压力**：单房伙伴手册约 400KB、庄园 8MB，自动备份总额约 1.5MB。多层大量手绘可能达到自动备份容量边界，需要进一步压力验收；完整庄园导出仍受自己的 8MB 格式边界约束。
