# 宠物小屋 v2.13.0

更新日期：2026-10-28。

## 商店显示方式

打开商店或仓库时，将当前房间保存为静态画面，并隐藏实时3D画布、暂停连续渲染。购买商品、切换伙伴或扩建后更新背景；关闭商店后恢复实时房间。

静止的弹窗不再持续叠加WebGL画面。伙伴动作计算仍可完成，因此坐在沙发上的伙伴可以站起，购买与扩建不会因为暂停显示而一直等待。

## 各自独立的角色

| 角色 | 独立外形 |
| --- | --- |
| 杏橘狐 | 保留原来的尖耳、衣着与蓬松尾巴 |
| 云朵兔 | 长软耳、梨形身体、宽大后脚、棉花尾 |
| 薄荷猫 | 猫脸和口鼻、胡须、短胖身体、弯卷长尾 |
| 可可熊 | 宽圆身体、圆耳、厚掌、奶油口鼻、蜂蜜围巾 |
| 星光企鹅 | 蛋形身体、短喙、扁鳍、蹼足和胸前星星 |

四个新增动物各自构建模型，不再以狐狸模型更换颜色和附件。共同保留坐下、站起、行走、浇水和庆祝的动作接口。

商城中五张角色图片由房间使用的 `createPetCharacter(sku)` 模型直接渲染，移除共用动物SVG模板。四个独立GLB文件与动作已重新导出。

## 验证

- 全量测试：362项通过，0失败、0跳过。
- 实际WebGL测试确认：商店静置时渲染计数不增加，画布隐藏、静态背景有效；关闭后渲染恢复。
- 验证桌面、手机尺寸、切换分类、仓库、购买、扩建、大小屋往返切换和卸载清理。
- 验证伙伴坐下时打开商店，仍能站起并完成购买。
- 四种动物改成相同灰色后，几何指纹及身体比例仍不相同。
- 五张512×512透明图片的模型ID、几何数量与源码哈希一致，防止图片沿用旧模型。

角色合览图在 `previews/角色实模-v2.13.png`。生成命令：`npm run render:pets`（需Playwright与Chromium，或使用 `PET_ROOM_PLAYWRIGHT_MODULE` / `PET_ROOM_CHROMIUM_EXECUTABLE` 指定本机路径）；导出独立模型：`npm run export:pets`。

使用本机试用地址时，请刷新页面以载入新版。原有积分、家具、配色和已解锁房型沿用。
