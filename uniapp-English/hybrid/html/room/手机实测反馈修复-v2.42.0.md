# 手机实测反馈修复 v2.42.0

日期：2026-11-11。对应反馈：聊天记录_20261111_201024.zip。
范围：仓鼠屋前端、仓鼠屋独立后端，以及 App 内仓鼠屋副本。学习、词库和管理后台业务代码未在本次修改。

## 本次五项调整

1. **点击地面误报**：普通地毯、墙面摆件不再发送家具互动请求。可到达的地面仍用于宠物移动；沙发、灯、植物及活动家具保留互动校验。补正主宠物通过根节点进行触摸命中判断。
2. **种植提示操作过期**：原数据库 SQL 将 UTC 时间再次按本地时区解释，当前机器产生 8 小时误差。小屋生活与在线统计改用不受数据库会话时区影响的 UTC 毫秒数，不再二次换算。手机操作编号由近期服务器时间加单调计时生成，手机时钟不准也可正常操作。过期请求只刷新最新状态，等待用户再次确认；网络失败保留原操作编号。切换到其他操作时先核对旧操作，避免重复消耗或卡住后续操作。旧奖励回执不能覆盖更新的装修。
3. **横屏好友页无法滚动**：短横屏改为两行紧凑顶部区域和独立滚动列表，聊天输入与记录分栏。保留触摸滑动、鼠标滚轮与键盘访问。好友页和参观页打开时隐藏背后的小屋名牌。
4. **参观邀请提醒**：收到新的待确认邀请时显示邀请文字，并尝试短震动。相同邀请不会随轮询重复震动；不支持或拦截震动的浏览器仍可看到文字，邀请必须手动接受。
5. **参观界面简化**：删除顶部大块标题、说明与文字互动按钮，房间使用整个画布。直接点主人宠物打招呼、点家具互动。左下角保留返回和楼层图标；只有互动进行时显示结束互动图标。楼层列表点击后展开，选择后收起。错误和连接问题仍有可见提示，常规状态保留给辅助阅读。
