## 更新内容

- 花园：立体草地、木质花坛、奶油围栏、条纹花架、石板小路、花盆、浇水壶及种子包。作物从小苗逐渐长大；系统减少动态效果时停止摆动。
- 手机交互：三格种植切换、种子卡、成长进度、浇水及收获按钮。竖屏充分使用屏幕高度并横向滚动功能栏；横屏左右分区，保留连续滚动。iPad 和电脑继续自适应。
- 家具：购买和取出时优先寻找靠前、较容易点击的空位，保留碰撞校验及完整候选位置。商店成功摆入后提供“调整刚摆好的家具”，直接进入装修并选中该件家具。
- 全屏：即使没有原生方向锁定能力，也尝试进入全屏。浏览器拒绝旋转时保留已经成功的全屏，提示打开手机自动旋转并横放；不做 CSS 强行旋转和比例拉伸。
- 测试入口：电脑 localhost 的模块请求原先被代理转发的 Origin 拦截；在外层来源校验通过后，将可信请求的内部 Origin 与 Host 一起归一化。未授权访问仍被拒绝。加载中、启动资源失败或票据失效时提供回到测试首页的入口。
