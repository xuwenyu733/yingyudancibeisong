# 商城精修、等级徽章与多框架验收

版本：2.14.0；日期：2026-10-28。基于上一版继续修改，原有积分、产权、墙色、地砖与房型解锁存档保持兼容。

## 界面与模型

商城家具、地砖、挂件以及屋内/仓库物件新增41张实际模型商品图，伙伴继续使用各自的5张实际模型图。商品图片与运行时模型来自同一套工厂，附带源码和图片哈希，避免以后改模型却沿用旧图片。

10件商城家具补充釉线、书页、镶边、刻纹、铆钉、花饰或缝线；8款地砖与12种挂件按主题增加角饰、嵌花与浮雕。卡片增加材质说明和配色色卡，图片展示区域加大。家具原有碰撞范围保持，最大房型的地砖为3–5个材质批次，最多约1.34万三角形。

商店仍使用静态房间背景：打开时隐藏、暂停实时3D绘制，购买或扩建后更新背景，关闭后恢复，保留上一版的稳定性处理。

## 已发现并修复的问题

1. **Shadow DOM不带样式**：原来把样式一律加入Document，封装组件内无法使用。现按Document或所属ShadowRoot共享和释放样式。
2. **封装组件内快捷键和拖入失效**：Document取得的是外层宿主，导致焦点、Esc/R和画布命中判断错误。现从组件所属树解析焦点与命中，开放和封闭ShadowRoot均有浏览器回归。
3. **样式一直等待或失败后无法重试**：现有超时边界，失败时释放样式引用和缓存；加载中卸载也会结束ready并清理资源。非法加载时限在创建渲染器前拒绝。
4. **徽章刷新丢失键盘焦点**：性别或等级变化重建勋章墙时保留原勋章焦点，卡片消失则转到搜索；昵称草稿不会被状态刷新覆盖。
5. **适配器与类型不完整**：Uni H5此前没有完整透传配置、状态/事件及重挂API；现已补齐。增加Svelte适配器，补齐新商城分类、墙色/地砖指令和暂停绘制指标的声明。
6. **多个打包副本的SVG渐变冲突**：徽章和备用商品插画使用模块命名空间，避免不同副本产生相同渐变ID。
7. **发布产物混入依赖与生成缓存**：新增npm忽略配置，ZIP与npm包均排除生成宿主、依赖和缓存。`npm pack --dry-run`确认41张物品图、5张伙伴图都保留，没有生成目录泄漏。发布脚本同时更新package.json版本。
