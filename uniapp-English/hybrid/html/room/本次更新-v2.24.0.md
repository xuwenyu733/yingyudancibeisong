# 本次更新 · v2.24.0

发布日期：2026-10-29

基于 v2.23.0 继续完善，共三项改动。

## 1. 宠物按真实动物方式移动

之前宠物行走都是"站立迈步"的通用走法，这轮按真实动物的移动方式重新烘焙了每只宠物的步态（GLB 动画已按新步态重出）：

| 宠物 | 真实动物移动方式 | 现在的小屋表现 |
|---|---|---|
| 薄荷猫 | 猫科四足爬行 | 身体放平前倾，四肢着地，左前腿+右后腿同时迈（对角步态），头微抬保持前视 |
| 可可熊 | 熊科四足爬行 | 同样四足放平对角迈步，身体前倾幅度略缓 |
| 杏橘狐 | 狐科四足小跑 | 前倾小跑、竖直起伏轻、尾巴放低拖行，前肢对角摆动 |
| 云朵兔 | 兔科跳跃 | 蓄力压低身体→腾空跳起→落地缓冲，双脚同进同退，耳朵尾巴随跳起伏 |
| 星光企鹅 | 企鹅没有站立行走 | 保持直立不迈大步，小幅快走并左右摇摆身体，鳍微微张开保持平衡 |

实现口径说明：企鹅真实移动是直立摇摆（不会像猫狗那样四足放平），因此按"摇摆直立小步"处理；杏橘狐按真实狐狸四足小跑处理。

## 2. 单宠制清理：去掉"多只宠物"暗示

商店宠物页不再显示"已收藏 N/M、收藏进度、下一件收藏、心愿收藏"这类收集多只宠物的文案，改为：

- 收藏进度区只显示一行：「每人同时只养一只」；
- 标题显示当前伙伴名字（如「当前伙伴 · 杏橘狐」），还没伙伴时显示「还没有自己的伙伴」；
- 宠物卡的 ☆ 心愿按钮改叫「把 XX 设为想入住的伙伴」，语义从"收藏"变为"想请来入住"。

家具 / 地砖 / 墙上挂件的收藏目标不受影响（它们本来就可以拥有多件）。

## 3. 好友进家门禁：从"数量上限"升级为"白名单"

之前只有"好友进家上限 1–3 位"，现在家长设置里多了「好朋友名字」名单：

- 默认已登记：小桃子、小石头、小月亮、豆豆（可增删，最多 8 位，每位名字不超过 8 个字）；
- 名单内好友：按上限进家，回家时可能留下带名字的留言；
- 名单外的人：被拦在门口，气泡提示"只有登记的好朋友才能进小屋玩哦～"；
- 名单为空：暂不接待任何客人（提示"还没有登记好朋友…"）；
- 原有"好朋友进家上限 1–3 位"继续生效，名额优先给名单里的朋友。
