# 朋友来访可见修复 · v2.39.0

问题：原参观功能只在客人端显示主人的房间快照，主人没有接收来访状态，因此看不到客人。

现在客人真正打开房间后，会同步来访状态。主人看到带“客人”名字牌的人物，以及来访人数和所在楼层；不在同一层时可点“去看看”。主人可结束参观。客人返回自己家、切换楼层、进入后台或失去连接后，会相应更新或清理。正常来访约 3 秒内同步，断线约 15–18 秒内清除。

客人是临时人物，自己的宠物仍只有一只。人物不加入宠物、家具或装修存档；客人没有修改主人存档的权限。本次同步来访和所在楼层，不同步自由行走坐标或主人即时装修。

后端程序 1.6.4，数据库结构继续使用 1.6.2，无需建表或迁移。好友关系、邀请有效期、屏蔽和撤销状态仍由 MySQL 核验；实时来访记录采用当前单 Node 服务进程的内存状态、心跳和超时清理，不保存永久在线记录。未来采用多进程或多实例部署时，需要将来访状态改为共享存储或消息服务。

附带修复：自动调整画质关闭或恢复阴影时，重建相关材质程序，避免部分 WebGL 驱动继续使用已释放的阴影纹理导致房屋不可见。

验证包括真实 MySQL 权限与楼层校验、临时双账号浏览器参观、跨楼层、主人结束邀请、断线过期、原宠物与布置不变，以及 PC、手机横竖屏和 iPad 布局。浏览器测试明确切换阴影关→开→关并检查真实画面像素覆盖，防止仅通过页面状态而漏掉模型消失。验证使用隔离临时账号并在结束后清理，不改写手机实测 A/B 账号和历史报告。安卓真机新版本仍需用户现场复核。
