# 宠物小屋 v2.20.0

日期：2026-10-29。基于当前 v2.19.0 测试模板；原始 ZIP 保留。历史版本说明用于回溯，当前行为以本文为准。

## 本轮完成

- 取消小院平铺及“是否叠到上一层”，只支持城堡楼层。每层一间，新房自动向上添加，最多六层；各层布置独立、积分和收藏共享。
- 兼容旧平铺存档：按原楼层和原顺序整理为连续楼层，保留房间 ID、名字、布置、仓库、配色及当前房间，不删除房间、不扣积分。只在实际迁移时保存，不在查看时反复写档。
- 等级勋章：在个人主页点当前大勋章或五枚等级预览，可看获得时间与等级门槛。未解锁的勋章明确显示“尚未解锁”。
- 成就：在个人主页点已获得成就，可看首次获得时间。新增精确时间包含秒；刷新、重复查看、重放奖励不会改变时间。
- 家具、地砖、墙挂件、宠物及已记录礼物：在“伙伴手册 → 图鉴册”点亮格子，可看获得时间、来源、获取者和到家第几天。补齐新购地砖此前遗漏的首次时间记录。
- 历史记录如只有日期，显示“具体时间未记录”；没有可信日期或时间，显示“获得时间未记录”。不会拿升级或查看时刻冒充旧物件、旧成就的获取时间。
- 删除“寄一张小屋明信片”：入口、下载逻辑、相关提示及公开 `exportPostcard` 接口均移除。存档导入导出保留。

## 闪屏修复

1. 画布缓存尺寸和像素比，相同 ResizeObserver/窗口回调不再重设绘图缓冲；真实变化后同一任务内重新绘制，避免露出被清空的背景。
2. 商店暂停画面改为 Canvas2D 同步复制，复制完成后才隐藏 WebGL；不再等待 PNG 图片解码。复制失败保留可见的实时画布。
3. 商店打开时，宠物短反应不会来回切换实时画布和静态层；动画完成后统一更新一次静态画面。关闭面板前先绘制，再恢复实时画面。
4. 个人主页后台刷新不再每半秒禁用、启用按钮。数据未变时跳过重绘，日历、周报和备份保留原节点与焦点；慢速旧结果不会覆盖较新的签到结果。

## 测试与使用

- 双击 `StartEstatePreview.cmd`，或运行 `python serve.py --port 8870 --preview estate`。测试地址：http://127.0.0.1:8870/?preview=estate 。仅当前电脑可访问，端口被占用时以启动窗口打印地址为准。
- 浏览器实测：原两层继续保留；自动新建第三层糖果画室，余额不变；新购蜂蜜奶油砖显示精确秒和第 1 天；图鉴未发现破图；名字页已没有明信片；检查时控制台无 warn/error。
- 回归覆盖：旧平铺存档迁移、唯一连续楼层、勋章与成就首次时间、历史未知时间、失败回滚、重放购买、地砖记忆、档案往返、画布尺寸幂等、同步底图及主页稳定刷新。完整测试结果见交付目录发布日志。
- 六组依赖额外 Playwright 环境的历史浏览器自动用例本机未运行；本轮实际网页操作使用内置浏览器完成。尚未完成真实 iOS/Android 和不同 GPU 的长期运行验收。

## 之后迁移的接口

```js
import {mountPetEstate} from './estate-house.js';
const estate = mountPetEstate({container, storageKey:'your-namespace', onInteraction(plan){ /* 对接宿主反馈 */ }});
await estate.ready;
await estate.api.createEstateRoom({name:'新的小世界',template:'mint'});
await estate.api.selectEstateRoom('room-1');
estate.api.getEstate(); // mode 固定 castle；rooms[].floor 从 0 连续编号
estate.api.getProfile(); // profile.levelBadges[].acquiredAt / badges[].acquiredAt
estate.dispose();
```

旧调用传入 `stacked:false` 仍会向上新增楼层；新类型不再提供该参数。旧 `setEstateMode('courtyard')` 返回不支持，不会恢复平铺。音乐仍由设计者锁定曲目，用户保留静音和音量调节。

## 仍未完成

- 另一边的新版本还没有目录，尚未迁移或联调；当前包和事件接口已准备好。
- 城堡是楼层目录加逐层 3D 房间，尚无整栋 3D 城堡、楼梯穿行和结构编辑。
- 自由画笔、双指连续旋转、独立成长阶段模型、完整搬家运镜、叼礼物回家、专门蜷睡打呼、语音念昵称、全部成就专属美术仍未制作；现有对应功能是预设或基础动作。
- 礼物暂为独立装饰，还不能像普通家具一样自由拖动、旋转及入库。
- 没有新增云同步、账号服务或服务端时钟校验；数据仍保存在本机。旧记录缺失的真实获取时间无法事后补造。
