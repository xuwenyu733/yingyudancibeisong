# 房型布局与存档备份等六项更新 · v2.17

> 交付包：`original-pet-room-v2.17.0.zip`（父目录）。本版聚焦「收藏与还原」：真实缩略图、装修撤销重做、每房型独立布局、商城心愿目标、成就摆进房间、存档备份入口。

## F1 · 家具栏换成真实缩略图 + 筛选

- 底部家具栏不再用 Emoji 占位：每个条目直接显示 `assets/products/previews/<sku>.png` 实拍预览图（加载失败自动回退为按名称分类的 Emoji，绝不显示叉图）。
- 新增「全部 / 家具 / 挂件 / 仓库」四个筛选按钮：未摆放的归「仓库」，摆在地上的归「家具」，挂在墙上的归「挂件」（支持 `aria-pressed` 高亮；筛选后计数同步更新，全部为空时显示空态提示）。
- 预览图映射集中在 `product-previews.mjs`，缩略图与回退逻辑在 `strip-thumb.mjs`，样式在 `room.css`。
- **发布前回归修复**：缩略图加载失败后打上失败标记，刷新家具栏不再重复发起同一张坏图的加载请求，直接保持 Emoji 回退。

## F2 · 装修支持撤销、重做

- 装修模式里，拖动落定、90° 旋转、调整碰撞盒都会记入历史；点装修面板的「撤销 / 重做」或按 `Ctrl/⌘+Z`（撤销）、`Ctrl/⌘+Shift+Z` / `Ctrl/⌘+Y`（重做）即可回退/恢复上一步，**不用取消整次装修**。
- 只记录“变换型”操作：摆放、收回仓库、从仓库取出会清空历史栈，避免恢复到已注销的家具；栈上限 40 步。
- 历史栈实现 `edit-history.mjs`（纯函数、可测）。
- **发布前回归修复**：布局快照恢复失败时（`layout-manager.restore` 返回 false 而非抛异常）不再误报「已撤销上一步」——改为明确提示「这一步暂时无法恢复，已清空撤销记录」并清空历史栈；退出装修（保存或取消）即清空撤销/重做栈，防止下一个装修会话撤销到上一会话的残留快照。

## F3 · 每种房型独立保存布局

- 初始小屋 / 温馨大屋 / 宽敞大屋各自记住自己的摆放方式：搬家换房时自动恢复该房型上次的布置；第一次进新档位时沿用当前布置。
- 存档结构升级为 `account.layouts[房级]`（保留 `account.layout` 作为当前房级别名），旧档自动兼容：读档时把当前布局回填到对应槽位，不丢家具。
- 切到更小的房子放不下时仍按原有 NO_SPACE 语义拦截并提示；切换成功后会按目标房型的布局重新摆放并再次存档。

## F4 · 商城增加自选心愿目标

- 每个商品卡片新增「☆ 心愿」星标：点一下设为该类别的自选心愿目标，再点取消；心愿持久化在 `${storageKey}-wish-v1`。
- 收藏目标卡改为优先展示你自选的心愿（金框 + 星标 +「心愿收藏 · xxx」），心愿已拥有/下架时自动回退为最便宜的未拥有物品。
- 每个分类新增工具条：**搜索名称/描述、价格排序（低→高 / 高→低）、只看未拥有**，筛选实时生效并带空态提示。
- 纯函数在 `shop-tools.mjs`，面板在 `shop-panel.js`，样式在 `shop.css`。

## F5 · 让成就真正摆进房间

- 解锁的勋章自动出现在房间里：**成就墙**（背墙两排画框，最新解锁的最显眼，最多 6 枚）+ **展示柜**（背墙右侧玻璃展柜，承接墙上放不下的更早成就，最多 2 枚）。
- 徽章直接复用现有 SVG 勋章渲染成真实纹理（`achievement-art.mjs`），不新增素材；性别切换、新勋章解锁、房间扩建/换档都会自动刷新。
- 展示体未注册进布局管理器（只读展示），不可拖动、不占碰撞、不进存档；相关实现 `achievement-display.mjs`。

## F6 · 提供存档备份入口

- 我的主页新增「存档管理」区：**立即备份**、**导出存档（下载 JSON）**、**从文件恢复**，以及**最近 3 份备份**列表（可单份恢复/删除）。
- 每次装修落定或房间扩建后自动留一份快照（2.5 秒防抖），最多保留最近 3 份、总量 1.5MB，超限自动丢最旧；备份与主存档分键存储（`<storageKey>-backups-v1`），不互相干扰。
- 恢复流程复用存档校验与锁（`storage.mjs`），成功后提示重新挂载房间生效；房间 API 新增 `createBackup / listBackups / restoreBackup / removeBackup / exportSave / importSave`。
- 实现：`backup.mjs`（纯函数 + 锁）、`room.js`（API）、`scene-profile.js`（UI）、`profile-upgrade.css`（样式）。
