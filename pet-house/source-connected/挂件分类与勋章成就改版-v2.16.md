# v2.16.0 挂件、等级勋章与成就

## 挂件集中管理

商店购买的挂件和小屋自带装饰画集中到「墙上挂件」，不再重复列入「屋内家具」。已挂上墙的可直接收回仓库，在仓库的可直接免费摆回墙上。仓库保留实际收纳物品，地面家具继续由「屋内家具」管理。

## 等级勋章重绘

保持1、4、8、12、16级五档进阶与原经验条件，替换共用头像式勋章。

| 档位 | 男孩 | 女孩 |
| --- | --- | --- |
| 1级 | 星途罗盘 | 晨露铃兰 |
| 4级 | 银隼守卫 | 蝶舞珍珠 |
| 8级 | 曜金圣骑 | 蓝鸢花冕 |
| 12级 | 苍雷龙翼 | 月羽流晶 |
| 16级 | 天穹执星者 | 极光星后 |

五档分别绘制轮廓，随等级提升增加金属、珐琅、宝石、冠冕或翼部细节。主页入口、当前等级与进阶预览使用同一套等级图案。

## 成就拥有独立造型

原成就墙复用了「当前等级勋章 + 分类小标记」，所以多个成就看起来相同。本次新增 `achievement-art.mjs`，与等级绘制器分开。

19项成就各有独立主题，男孩与女孩共38款不同造型；例如初次签到是启程明灯/晨露花灯，学习1小时是时光砂漏/茶香书时，收藏家是四珍陈列/珠光珍匣，累计两次扩建是天空工坊/水晶花房。

- 造型、标题随男女样式切换；原成就ID、解锁条件和解锁日期保持。
- 等级变化只更新等级勋章，不会把成就统一改成当前等级的样式。
- 未解锁成就保留彩色预览与实际条件；点击可放大查看图案和详情。
- 搜索支持造型名、原成就名与条件，切换性别时保留同一成就的键盘焦点。
- 继续使用静态矢量绘制，无循环光效或滤镜。
