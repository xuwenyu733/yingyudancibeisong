# 宠物小屋 v2.21.0

日期：2026-10-29。基于 v2.20.0 继续开发，本包包含此后已完成的互动补全与宠物四边安全距离修复。原 v2.20.0 ZIP 保留，当前行为以本文、现有界面和类型声明为准。历史命名开发目录不代表包内版本。

## 已完成并包含在包内

- **家具手绘**：独立画纸上的自由画笔、选色、粗细、透明橡皮、撤销、重做、可撤销清空与逐件保存。画稿贴在家具顶面，刷新、房型与楼层存档保留；保存失败保留草稿，未保存时拦截切换家具与楼层。
- **礼物家具**：签到、口令与回访奖励对应独立免费 SKU，有四类真实模型，支持摆放、旋转、缩放、换色、贴纸、手绘与收回仓库。楼层共享产权、独立摆放；到期保留获得时间与收藏记录，禁止重新取出，到期收纳写盘失败会保留可见模型与碰撞并重试。
- **宠物动作与成长**：五宠的欢呼、鼓掌、蹭蹭、闭眼、蜷睡与呼吸；轻柔合成呼噜遵守静音和音量。寻宝使用可达导航往返、嘴部携物、回家放下，中断清理道具。幼年、少年、成年分别应用程序化比例及服饰，少年需 7 个活跃日期，成年需 30 个活跃日期且累计学习 2 小时，手册展示下一阶段任务。
- **成就家具纹样**：全部 19 枚成就各有程序绘制的纹样和配色，获得后可关联家具并在手册选择；未解锁不能应用。成就纹样和自由画稿分层保留。
- **昵称语音**：家长设置可开启“语音喊昵称”，默认关闭；仅使用设备本地中文语音，真实点击后解锁，支持试听、去重及取消。设备没有本地中文语音时明确提示，继续使用文字气泡。
- **搬家与引导**：切楼层保留旧画面并显示搬运遮罩，新房有短镜头移动、墙体视觉变化和纸箱进出；可以跳过，支持减少动态效果。首次引导由实际进入装修、拖动、旋转、保存事件推进，可以跳过或重播。
- **双指操作**：普通家具双指连续旋转、等比缩放，设计尺寸 0.5～2 倍限幅；碰撞失败、取消、第三指或退出会回滚。墙挂件双指调整大小，换墙沿用原按钮。
- **宠物边界修复**：宠物中心距房屋四边保留身体半径加可见空隙，包含开放前沿和四角。键盘、点击、巡游、座位接近统一遵守；点边沿不会让坐着的宠物起身排队。贴边座位或通路不足时提示调整家具。旧布局保留；缩房先找安全落点，失败精确回滚，旧座位兼容规则不会放宽实际行走限制。
- **此前功能保留**：城堡仅叠层、每层独立布置、全房间共用积分与收藏、一键全收纳、宠物与房间起名、房间名牌、图鉴、获得时间与到家天数、签到、全屏成就庆祝、儿童配色、家具缩略图、设计者锁定音乐及用户静音/音量。原有闪屏修复保留，寄小屋明信片功能已删除。

## 启动与操作入口

1. 完整解压 ZIP 到新文件夹，双击 `StartEstatePreview.cmd`。需要 Python 3.8+，无须安装 Python 包。
2. 默认地址是 `http://127.0.0.1:8870/?preview=estate`。已占用时自动尝试后续端口，以启动窗口打印的地址为准。只供当前电脑访问。
3. 伙伴手册 → 换装创造：家具纹样、自由手绘与宠物装扮；成长花园：成长任务及口令；家长设置：昵称语音、音量和存档管理。商店/仓库与装修栏可摆放礼物家具。
4. 方向键/WASD 移动，空格停下，点击屋内地面寻路；家具挡住通路时先在装修里移开或收纳。城堡/楼层可添加和切换楼层。

也可运行 `python serve.py --port 8870 --preview estate`。要进行开发回归，安装 Node 20+ 后运行 `npm test`；额外 Playwright 用例需另行配置其依赖。

数据属于当前浏览器当前地址的本机存储。换端口、浏览器或设备不会自动带入旧进度；可从家长设置导出完整存档，在目标地址导入。ZIP 不包含浏览器测试存档，也不会清空目前运行页面的存档。

## 仍未完成或需要外部条件

1. **制作级资产**：目前动作、成长形体、服饰、纹样和呼噜主要由程序生成；尚无三套独立雕刻的成长模型、录制动作、专业呼噜音轨和逐成就手绘材质包。
2. **任意曲面作画**：当前是在画纸上创作并贴到家具顶面，尚未支持直接对模型任意曲面/多面涂抹或 UV 编辑。
3. **整栋城堡与长剧情过场**：目前为逐层房间与有限搬家动画，没有整栋城堡同屏、楼梯穿行、连续结构编辑和长篇分镜。
4. **真实设备与长期测试**：真实 iOS/Android 双指手感、多浏览器 GPU、持续运行、自然七天到期和人工音效试听尚待验收；六项历史可选 Playwright 用例没有执行。
5. **旧物准确日期**：历史存档没有的真实获得时间无法补造，仍明确显示日期/具体时间未记录。
6. **云端与正式积分服务**：未新增账号、跨设备同步、服务端时钟/签到和积分校验，仍使用本机存储与时间。正式学习数据需宿主调用现有 `creditLearning` 接口。
7. **另一边新版本迁移**：目标目录尚未提供，本包只完成当前模板，未进行跨项目迁移和联调。
8. **大规模画稿存储压力**：单房伙伴手册约 400KB、庄园格式约 8MB、自动备份总额约 1.5MB，多楼层大量手绘可能触及容量边界，仍需压力验收。

## 迁移入口

城堡挂载入口为 `estate-house.js` 的 `mountPetEstate`，单房入口为 `pet-house.js`。API 类型分别见 `estate-house.d.ts`、`room.d.ts`，现成组件在 `frameworks/`。模式继续固定 `castle`，旧平铺存档保留内容并整理为连续楼层。音乐曲目由 `designer-config.mjs` 控制，用户仍能静音和调音量。

本包可以独立运行。将来收到另一边的新版本目录后，再迁移这些模块与事件并做跨项目回归。
