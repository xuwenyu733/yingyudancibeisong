**不懂数据库也可以这样看**

在 Navicat 左侧展开 `pet_room` → **视图**。以后主要看以“新手”开头的中文入口：

| 中文入口 | 什么时候看 |
| --- | --- |
| 新手_00_使用指南 | 不知道从哪里找时，先打开它 |
| 新手_01_账号总览 | 看昵称、可用积分、当前房间和最近保存时间 |
| 新手_02_每层房间 | 看每层叫什么、房间大小、正在使用哪层 |
| 新手_03_房间存档 | 看自动保存和自己命名的存档点 |
| 新手_04_房间家具 | 看当前房间实际摆出的家具 |
| 新手_05_家具仓库 | 看已经拥有但本层尚未摆出的家具 |
| 新手_06_积分记录 | 看购买、扩建和积分收支 |
| 新手_07_宠物伙伴 | 看宠物种类、昵称和当前伙伴 |
| 新手_08_商品价格 | 看中文商品名字和所需积分 |
| 新手_09_好友关系 | 看谁和谁是好友、申请是否同意 |
| 新手_10_参观邀请 | 看谁邀请了谁、是否到期 |
| 新手_11_联网账号 | 直接看每个人可分享的账号 ID |

双击入口即可查看，列名和状态均为中文，时间按北京时间显示。账号编号、家具编号等技术字段放在后面，通常不用看。记录中的“未记录金额”表示旧数据没有保存金额，不表示免费或 0 积分。

这些入口是只读的，查看时不会误改游戏数据。更换装修、读取房间存档等操作仍在小屋里完成。

也可以双击 `启动小屋.cmd` 后打开 `http://127.0.0.1:8899/database`。目录页默认显示使用指南，左侧点击“房间存档”等中文按钮，顶部按账号名称和楼层筛选。

当前电脑的中文入口已经安装。给其他已安装旧版的电脑使用时，关闭旧服务，运行 `升级中文入口.cmd`；它先备份，再新增中文视图。新电脑首次安装继续使用 `初始化数据库.cmd`。
