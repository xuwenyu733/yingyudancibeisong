# 仓鼠屋 v2.30.0：生活玩法、好友参观和唯一伙伴

本版只更新 3D 仓鼠屋、其 MySQL 服务和必要的小屋 App 接入文件。学习首页、背单词、家长端和管理端业务不改动。手机继续横屏使用，不设置每日上限、强制休息或定时解封。

## 邀请朋友来家里

1. 点击画面侧边的“邀好友”。如果还不是好友，先在朋友页输入对方主页上的完整账号 ID，发送申请，由对方同意。
2. 在“我的好友”中，点击对方旁边的“邀请参观”。先完成装修和手绘保存，房间同步成功后才能发出邀请。
3. 对方在小屋中会收到参观提示，点击“查看参观邀请”，再点击“接受并参观”。也可以从朋友页的“参观邀请”进入。
4. 对方可以查看你家的一楼、二楼和当前伙伴；参观采用保存好的房间布置，不能替主人购买、移动或删除家具。
5. 点击“返回我的小屋”回家。主人可以“结束邀请”；移除好友、屏蔽或邀请过期后，也会停止参观。结束后不会复用旧邀请。

每个账号只显示当前的一只宠物。商店不再提供额外宠物购买，手册只展示当前伙伴；参观也不会把来访者的宠物叠加进主人家。旧版动物模型资源和历史数据保留，避免破坏原有存档。

异地朋友需要连接同一台已部署的服务器。本机 `127.0.0.1` 只能在这台电脑上使用；当前部署包支持以后配置公网域名和 HTTPS。

## 从“生活”开始

| 页面 | 能做什么 | 如何保存或获得奖励 |
|---|---|---|
| 主题委托 | 接取阅读角、森林、星空、童话和手绘主题任务 | 按当前楼层实际摆放验收；材料和纪念摆件只发一次 |
| 家具图册 | 点亮森林、星空、童话三套家具 | 按账号已拥有的家具计算，领取套装奖杯，不消耗家具 |
| 蓝图制作 | 用木板、布料、颜料和星砂制作九件可摆放家具 | 制作后进入真实仓库；星空和童话蓝图随故事解锁 |
| 摄影室 | 自然、歪头、跳跃拍照，添加边框、文字、贴纸和缩放 | 相册最多八张，可下载明信片或发布到好友展厅 |
| 种植园 | 三个种植格，胡萝卜、草莓、薄荷，浇水和收获 | 按服务器时间成熟，成熟后不会枯萎；材料包和种子按账号保存 |
| 好友展厅 | 发布主题作品及装修码，给好友作品送表情或收藏 | 仅自己和互为好友的人可见；可以撤下自己的作品 |
| 厨房订单 | 制作饼干、果汁、茶，完成邻居订单 | 消耗真实食材，送出料理后获得小屋星星和材料 |
| 邻里故事 | 三章故事，选择对话并完成装修、种植、作品展目标 | 每步保存，章节完成领取纪念物并解锁蓝图 |
| 职业 | 设计师、园艺师、厨师，累计经验、完成职业任务 | 解锁对应的 3D 帽子和纪念奖杯；切换职业保留进度 |

生活材料、星星、故事和职业在一楼与二楼之间共用。小屋星星是生活玩法的独立资源，不扣学习积分。制造出来的家具两层都可使用；到另一层时先放在仓库，防止自动打乱装修。

房间命名备份仍按楼层独立保存。读取旧装修后，如果当时的家具记录还没有后来领取的奖励，可在“主题委托”点“找回已领奖品”，核对并找回领取过的家具和摆件；不会重复获得材料或星星。

手机横屏中，列表使用翻页按钮；商店、仓库、生活功能和邀请入口在侧边。若设备不支持直接下载照片，可以长按浏览器打开的照片保存；原生 App 的相册保存分支仍需安装到真实手机验收。

## 数据库怎么找

本机数据库结构已补到 1.6.0：45 张基础表、20 个视图。新增 6 张生活相关表及 2 个中文视图，原房间、积分和好友表继续使用。

- “新手_14_小屋生活进度”：查看昵称、用户 ID、星星、中文职业、任务数量、故事进度、材料包和种植格。
- “新手_15_好友作品展厅”：查看作品、作者、主题、楼层、四位装修码、表情和收藏数量。
- “新手_03_房间存档”：看各层房间和命名备份。
- “新手_13_仓鼠屋在线时长”：仅统计在线时间，显示“可进入（不限时）”。

其他电脑升级时，先完成旧版迁移及取消限时迁移，再运行“升级小屋生活数据库.cmd”。脚本会先备份；服务启动只检查数据库结构，不会自行建表。本机已完成升级和升级前完整备份，无须再初始化数据库。分享包不带数据库口令、真实用户数据或本机完整备份。

本版包含前面选择的第 1–9 项玩法；第 10 项多人公共小镇未加入。好友参观展示主人的已保存房间，不包含多人同时操控角色。
